  <action>
Reemplazar el contenido de `next.config.mjs` con la siguiente configuración:

```javascript
/** @type {import('next').NextConfig} */
const nextConfig = {
  experimental: {
    serverComponentsExternalPackages: ['@sparticuz/chromium', 'puppeteer-core'],
  },
};

export default nextConfig;
```

El archivo actual es:
```javascript
/** @type {import('next').NextConfig} */
const nextConfig = {};

export default nextConfig;
```

Por qué es crítico: Next.js 14 App Router bundlea todo el código de servidor por defecto. Los archivos binarios de `@sparticuz/chromium` son archivos `.br` (Brotli) que no son JavaScript — el bundler falla al procesarlos. Con `serverComponentsExternalPackages`, Next.js los trata como dependencias externas y no los bundlea.

Después de modificar, verificar que el build no tiene errores de TypeScript:
```bash
npm run build
```
